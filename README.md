# Amazon Customer Review Dashboard | Power BI

## Project Overview

The Amazon Customer Review Dashboard is an interactive Power BI dashboard created to analyze customer reviews, ratings, brands, and product categories.  
This dashboard helps understand customer satisfaction, rating distribution, brand performance, and category-wise review insights.

## Tools & Technologies Used

- Microsoft Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)
- CSV Dataset
- Data Visualization

## Dataset Information

The dataset contains Amazon customer review information including:

- Review
- Rating
- Brand
- Category
- Sub Category
- Verified Purchase
- Review Distribution
- Customer Feedback Data

### KPI Cards

- Total Reviews
- Average Rating
- Verified Purchase Count
- Number of Brands
- Number of Categories
